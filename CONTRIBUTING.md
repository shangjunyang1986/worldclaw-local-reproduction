# Contributing

Contributions are welcome when they preserve the clean-room and source-only
release boundary.

1. Do not submit model weights, official reference media, branded extracted
   assets, private datasets, tokens, or generated files without explicit rights.
2. Add tests for behavior changes and update the relevant public documentation.
3. Run `uv run pytest -q`, frontend tests, and the public-release audit.
4. Record upstream sources and SPDX license expressions for new dependencies.
5. Keep visual geometry, simulation collision, and navigation truth separate.

By contributing, you agree that your contribution is licensed under
Apache-2.0 and that you have the right to submit it.
