# Code of Conduct

We are committed to a respectful, harassment-free collaboration environment.
Be constructive, assume good faith, respect privacy and intellectual-property
boundaries, and critique work rather than people. Harassment, discrimination,
threats, doxxing, or deliberate misuse of project infrastructure are not
accepted. Maintainers may edit or remove harmful content and restrict access.

Report conduct concerns privately through the security contact configured for
the GitHub repository rather than posting personal information in an issue.
