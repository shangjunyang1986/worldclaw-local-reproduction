# Roadmap

## 0.1 — Source-safe foundation

- portable installation and environment diagnostics;
- unified CLI and external-model adapters;
- allowlist-built public source tree;
- versioned scene, asset, measurement, and quality contracts;
- lazy web preview and local GPU resource policy.

## 0.2 — Paper workflow

- prompt-to-WorldSpec planner interface;
- concept/reference approval and semantic-layout evidence;
- camera-calibrated regional object placement;
- bounded render-based object and terrain refinement;
- provenance lockfiles for every stage.

## 0.3 — Reproducible evaluation

- public CC0 benchmark scenes and golden CPU fixtures;
- self-hosted GPU integration tests;
- cross-machine artifact comparison and performance reports;
- stable plugin API for model and engine providers.

## 1.0 — Stable local production

- documented compatibility policy and migrations;
- authenticated multi-user deployment profile;
- progressive regional streaming and export profiles;
- independently reproduced release on a clean workstation.
